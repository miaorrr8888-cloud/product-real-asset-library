# product-real-asset-library

Python 3.10+, standard library only.
Run `python scripts/media_probe.py <file>` or `python scripts/xlsx_cellimage_map.py <book.xlsx>`.
Workbook relationship paths now support both absolute and relative targets.
Hash agreement establishes identical bytes, not official ownership or permission to reuse.

Published by miaorrr8888-cloud with AI-assisted development and cleanup. See PROVENANCE.md and LICENSE.
Validation: run `python -m unittest discover -s tests -v` from this repository root.
